# Site oficial do EQShift

Site estático pronto para GitHub Pages.

## Antes de publicar

Edite `config.js` e substitua:

- `SEU_EMAIL_DE_SUPORTE` pelo e-mail público de suporte/privacidade.
- `playStoreUrl` pelo link do EQShift na Google Play quando ele existir.
- `githubUrl` se quiser publicar um repositório público do projeto.

**Não coloque API keys, senhas, keystores ou segredos neste repositório.**

## Publicar de graça no GitHub Pages

1. Crie um repositório público, por exemplo `eqshift-site`.
2. Envie todos os arquivos desta pasta para a raiz do repositório.
3. No GitHub, abra `Settings` > `Pages`.
4. Em `Build and deployment`, escolha publicação a partir de um branch.
5. Selecione `main` e `/ (root)`.
6. Salve e aguarde a URL ficar disponível.

Exemplo: `https://SEU_USUARIO.github.io/eqshift-site/`

## URLs úteis no Play Console

- Política de Privacidade: `https://SEU_USUARIO.github.io/eqshift-site/privacy.html`
- Suporte: `https://SEU_USUARIO.github.io/eqshift-site/support.html`
- Dados e exclusão: `https://SEU_USUARIO.github.io/eqshift-site/data.html`
- Termos: `https://SEU_USUARIO.github.io/eqshift-site/terms.html`

## Importante para o app

O Google Play exige que a Política de Privacidade também esteja acessível dentro do próprio aplicativo. Antes da publicação pública, adicione no EQShift um link para `privacy.html`.
